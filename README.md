# SELO Voice Actor AI

واجهة عربية RTL مصممة للموبايل باستخدام React + TypeScript + Vite، وقابلة للتثبيت كتطبيق PWA.

## التشغيل
```bash
npm install
npm run dev
```

## الموجود في النسخة الأولية
- واجهة عربية متجاوبة مع شاشات أندرويد.
- كتابة النص وحساب الكلمات.
- اختيار إحساس الأداء (إعداد واجهة).
- التحكم في السرعة ودرجة الصوت.
- معاينة عبر أصوات النظام المتاحة في المتصفح.
- أساس PWA للتثبيت من المتصفح.

## توضيح مهم
المعاينة الحالية تستخدم خاصية تحويل النص إلى كلام في المتصفح؛ وليست استنساخًا للصوت ولا توليدًا بمحرك ذكاء اصطناعي. ربط محرك صوت عربي فعلي، والصوت المرجعي، وتصدير WAV/MP3 يحتاج خدمة خلفية ومحرك صوت مناسب.

هذه النسخة لا ترفع النصوص أو الملفات إلى خادم خارجي.
